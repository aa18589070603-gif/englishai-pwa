# EnglishAI V2

无需付费后端的静态 PWA。保留 V1 的本地 iPhone 视频导入、SRT/VTT 双语字幕、点击字幕跳转、逐句循环、录音与回放；新增六个学习入口。

| 入口 | 当前实现 |
| --- | --- |
| 字幕 | 导入、粘贴或载入示例双语字幕，点选句子跳转 |
| 跟读 | 视频原声、设备英文 TTS、录音回放；可试用浏览器语音识别并查看文字差异 |
| 听写 | 播放当前句并输入英文，显示缺少与多出的词 |
| 填空 | 从当前英文字幕隐藏一个单词，检查答案 |
| Quiz | 从至少三句有不同中文译文的字幕生成释义选择题 |
| AI 对话 | 明确标为待接入，需要另建 AI 服务后端 |

只载入示例字幕时，“播放本句”会使用设备英文 TTS；选择视频后改为播放视频原句。浏览器语音识别的可用性取决于浏览器、网络和权限，尤其是 iPhone Safari。文字差异反馈**不是发音评分**。设备 TTS 声音取决于系统安装的语音。视频、字幕与录音默认仅在当前页面内存中，刷新或关闭后需重新选择；浏览器语音识别可能由浏览器服务处理语音。

## 本地检查

无需安装依赖。运行 `node --test tests/core.test.js` 检查字幕解析与练习题逻辑。使用任意静态服务器打开根目录进行桌面预览；麦克风、语音识别与 PWA 安装应在 HTTPS 页面测试。

## iPhone 预览与测试

此 PR 合并之前，GitHub Pages 的 main 站点仍显示 V1。要在 iPhone 预览 V2，可将 `englishai-v2` 分支部署到单独的 HTTPS 预览站点，或使用支持 HTTPS 的静态预览服务部署此分支根目录。不要修改 main 的 Pages 来源。

1. 用 iPhone Safari 打开 V2 预览 HTTPS 地址。如需测试 PWA，点“分享”→“添加到主屏幕”，从主屏幕打开。
2. 选择相册或“文件”中的 MP4/MOV，再导入英文一行、中文一行的 SRT/VTT。点字幕，检查跳转、上一句/下一句和循环；关闭循环，检查句尾暂停。视频格式还需受 iPhone Safari 支持。
3. 打开“跟读”，测试英文朗读、麦克风授权、录音停止与回放。点击“尝试识别我的朗读”，检查支持提示、识别文字与差异反馈；若 Safari 不提供接口，按钮应禁用并提示原因。
4. 打开“听写”和“填空”输入正确及错误答案，检查反馈；打开 Quiz 选答案及下一题。最后确认“AI 对话”显示“待接入”。
5. 如以前安装过 V1，关闭并重开应用或刷新一次，再检查新入口。Service worker 缓存已升级为 V2。

## 部署

仓库保留纯静态结构。合并并准备上线时，可在 GitHub Settings → Pages 中选择所需分支根目录。当前开发 PR 不会更改 main 或其 Pages 设置。
